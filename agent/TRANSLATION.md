## Rules

1. Keep Markdown structure (headings, lists, blockquotes, links) isomorphic with the Chinese source.
2. Do **not** translate code, identifiers, file paths, type names, or commit hashes.
3. Translate Chinese comments inside demo listings; leave English source comments as-is.
4. Preserve citation form `` `file:line` `` and GitHub links.
5. Keep the book's calm, precise tone — technical, not marketing.
